# 06 · 部署与运行指南

## 1. 环境要求

| 依赖 | 版本 |
|---|---|
| Python | 3.10+（推荐 3.11/3.12，当前项目按 3.11 构建过 venv） |
| Node.js | 18+ |
| npm | 9+ |
| ffmpeg | 视频拼接/音视频后处理必需 |
| uv | 推荐（后端依赖管理，也可用 pip + venv） |

## 2. 后端初始化

```bash
cd xiaoyunque/xiaoyunque/backend

# 方式 A：uv（推荐）
uv sync --python 3.12

# 方式 B：无 uv
python -m venv venv && source venv/bin/activate && pip install -r requirements.txt

# 复制配置文件并填入 API Key
cp config.yaml.example config.yaml
```

> ⚠️ 本仓库自带的 `.venv/` 是另一台机器（`/Users/hu/...`）创建的，路径失效，**不要直接复用**，请按上面重建。

依赖清单：`requirements.txt` / `pyproject.toml` / `uv.lock`。核心依赖 FastAPI、uvicorn、yaml、requests、websocket-client、typer 等。

## 3. 前端初始化

```bash
cd xiaoyunque/xiaoyunque/frontend
npm install
```

## 4. 一键安装脚本

```bash
cd xiaoyunque/xiaoyunque
chmod +x install.sh && ./install.sh
# 跳过前端构建只装依赖：XYQ_SKIP_FRONTEND_BUILD=1 ./install.sh
# Windows：install.bat
```
脚本会检查 Python/Node/npm/ffmpeg、装依赖、复制 config.yaml.example → config.yaml。

## 5. 启动

```bash
# 后端（终端 1）
cd xiaoyunque/xiaoyunque/backend
uv run python api_server.py          # http://localhost:8000

# 前端（终端 2）
cd xiaoyunque/xiaoyunque/frontend
npm run dev                          # 开发模式 http://localhost:3000
# 或生产：npm run build && npm start
```

## 6. 健康检查

```bash
curl http://localhost:8000/api/health
# → {"status":"ok","timestamp":...}
```
打开浏览器：`http://localhost:3000`（前端）、`http://localhost:8000/docs`（API Swagger）。

## 7. 前端连接后端的环境变量

| 变量 | 作用 | 默认 |
|---|---|---|
| `BACKEND_API_URL` | Next.js rewrites 代理目标 | `http://127.0.0.1:8000` |
| `NEXT_PUBLIC_API_URL` | SSE 流式接口直连地址 | `http://127.0.0.1:8000` |

后端 CORS 默认允许 `http://127.0.0.1:3000`、`http://localhost:3000`；如需其他来源，用环境变量 `XYQ_CORS_ORIGINS=origin1,origin2` 追加。

## 8. 产物目录

```
backend/code/
├── data/
│   ├── sessions/            # 主流程会话 JSON
│   └── tasks/               # Pipeline 任务元数据 <task_id>.json
└── result/
    ├── image/<session>/     # 角色/场景/参考图
    ├── video/<session>/     # 视频片段与成片
    ├── script/              # 剧本/分镜数据
    ├── sandbox/             # 临时工作台产物 + history.json
    └── task/<task_id>/      # Pipeline 产物
```

## 9. 常见问题

| 问题 | 处理 |
|---|---|
| `Session not found` | session_id 不存在/被删；检查是否用了正确的 id |
| `Missing required model configuration` | 未填齐 `llm_model/vlm_model/image_t2i_model/image_it2i_model/视频模型`，去设置页或 config.yaml 配置 |
| 生成失败返回模型错误 | 对应平台的 API Key 未配置或额度不足 |
| SSE 不实时 | 确认流式请求直连 `127.0.0.1:8000` 而非经 Next 代理 |
| 端口占用 | 改 config.yaml 的 `server.port` 与前端 `BACKEND_API_URL` |
| venv 报错找不到解释器 | 删除 `.venv` 后重新 `uv sync` |
