# 03 · 数据模型与产物格式

> 前端渲染各阶段产物时，需要精确理解这些结构。会话状态保存在 `backend/code/data/sessions/{session_id}.json`。

## 1. Session 根结构

```json
{
  "session_id": "...",
  "current_stage": "storyboard",
  "status": {                          // 每阶段一个状态
    "script_generation": "completed",
    "character_design": "completed",
    "storyboard": "waiting",
    "reference_generation": "pending",
    "video_generation": "pending",
    "post_production": "pending"
  },
  "error": null,
  "artifacts": { ... },                // 各阶段产物（见下）
  "meta": {                            // 会话级生成参数
    "idea": "...", "style": "anime", "episodes": 4,
    "llm_model": "...", "vlm_model": "...",
    "image_t2i_model": "...", "image_it2i_model": "...",
    "video_first_frame_model": "...", "video_start_end_model": "...", "video_reference_model": "...",
    "video_generation_mode": "first_frame",
    "video_ratio": "9:16", "video_resolution": "720P",
    "enable_concurrency": true, "web_search": false, "expand_idea": true
  },
  "stage_progress": {
    "storyboard": {"phase": "...", "step": "...", "message": "...", "percent": 45, "updated_at": 172...}
  },
  "updated_at": 177...
}
```

状态值含义：`pending` 未开始 / `running` 执行中 / `waiting` 有产物待用户确认 / `completed` 已确认 / `stopped` 停止 / `error` 出错。

## 2. 各阶段 Artifact 结构

### 2.1 script_generation（剧本）

```json
{
  "session_id": "...", "version": 1,
  "title": "剧本标题",
  "logline": "故事梗概",
  "genre": ["奇幻"], "mood": "情绪",
  "characters": [
    {"name": "角色名", "character_id": "char_xxx", "description": "...", "role": "主角"}
  ],
  "settings": [
    {"name": "场景名", "setting_id": "set_xxx", "description": "..."}
  ],
  "episodes": [
    {"episode_number": 1, "act_title": "第1集标题", "content": "剧本正文"}
  ]
}
```

### 2.2 character_design（角色/场景设计）

```json
{
  "characters": [
    {"id": "char_xxx", "name": "...", "description": "...",
     "selected": "result/image/<session>/xxx.jpg",   // 空串=未选择
     "versions": ["...v1.jpg", "...v2.jpg"], "status": "done"}
  ],
  "settings": [
    {"id": "set_xxx", "name": "...", "description": "...", "selected": "", "versions": [], "status": "done"}
  ]
}
```
> `selected` 为空 → 阶段状态 `waiting`；全部选中 → `completed`。

### 2.3 storyboard（分镜）

```json
{
  "episodes": [
    {
      "episode_number": 1, "episode_title": "...",
      "segments": [
        {
          "segment_id": "seg_01_01", "segment_number": 1,
          "total_duration": 10,
          "characters": ["角色名"], "setting": "场景",
          "visual_prompt": "参考图提示词",
          "video_prompt": "视频提示词",
          "shots": [
            {"shot_number": 1, "duration": 5, "content": "镜头内容", "camera": "镜头语言"}
          ]
        }
      ]
    }
  ]
}
```
> 链路是 `episode → segment → shot`；**一个 segment = 一次视频模型调用**；`segment_id` 是全流程跨阶段关联主键。

### 2.4 reference_generation（参考图）

```json
{
  "scenes": [
    {"id": "seg_01_01", "name": "第1集-片段1", "index": 1,
     "description": "参考图描述",
     "selected": "result/image/<session>/seg_01_01_v2.jpg",
     "versions": ["...v1.jpg", "...v2.jpg"], "status": "done", "episode": 1}
  ]
}
```
> `scenes[].id` = `storyboard.episodes[].segments[].segment_id`。

### 2.5 video_generation（视频）

```json
{
  "clips": [
    {"id": "seg_01_01", "name": "第1集-片段1", "index": 1,
     "description": "片段描述", "duration": 5,
     "selected": "result/video/<session>/seg_01_01_v1.mp4",
     "versions": ["...v1.mp4"], "status": "done", "episode": 1}
  ]
}
```
> `clips[].id` = `segment_id`。

### 2.6 post_production（后期）

```json
{
  "final_videos": [
    {"episode": 1, "path": "result/video/<session>/xxx_ep1.mp4", "name": "第 1 集"}
  ],
  "final_video": "result/video/<session>/xxx_ep1.mp4"
}
```

## 3. 跨阶段数据同步关系

```
storyboard(segment.visual_prompt/video_prompt/duration/shots)
   │ 自动同步
   ├──▶ reference_generation.scenes (description)
   └──▶ video_generation.clips (description/duration)

script_generation 续写确认 → 同步 new_characters/new_settings 到 character_design，
                             new_episodes 到 storyboard
character_design 修改角色/场景描述 → 同步回 script_generation 元数据
```

## 4. PATCH /artifact/{stage} 请求格式

### storyboard —— 修改分集/片段/镜头
```json
{"episodes": [
  {"episode_number": 1, "segments": [
    {"segment_id": "seg_01_01", "total_duration": 10, "visual_prompt": "...", "video_prompt": "...", "shots": []}
  ]}
]}
```

### reference_generation —— 修改描述 / 选图
```json
{"scenes": [{"id": "seg_01_01", "description": "新描述"}]}
```
或按 id 直接选版本（旧格式）：
```json
{"seg_01_01": "result/image/<session>/seg_01_01_v2.jpg"}
```

### video_generation —— 修改描述/时长 / 选视频
```json
{"clips": [{"id": "seg_01_01", "description": "...", "duration": 5}]}
```
或：
```json
{"seg_01_01": "result/video/<session>/seg_01_01_v2.mp4"}
```

### character_design —— 选角色/场景图
```json
{"characters": [{"id": "char_xxx", "selected": "result/image/<session>/xxx.jpg"}],
 "settings":   [{"id": "set_xxx", "selected": "result/image/<session>/xxx.jpg"}]}
```

> 通用原则：PATCH 体中的列表项按 `id` 与后端已有产物合并；`selected` 填文件路径即表示用户选中该版本。
